## 2️⃣ IN-RACE STAGES & STAGE POINTS

This is the big one. I'm proposing we add **stages within each race**, similar to how NASCAR runs it. Here's how it would work:

**Example: 150-lap race**
- 🟡 Stage 1 caution at Lap 40
- 🟡 Stage 2 caution at Lap 80
- 🏁 Race finish (Stage 3) at Lap 150

At each stage caution, the **Top 5** earn bonus points:
| Position | Stage Points |
|----------|-------------|
| 1st | +5 |
| 2nd | +4 |
| 3rd | +3 |
| 4th | +2 |
| 5th | +1 |

Stage 1 and Stage 2 both award these points. Then the **race finish** pays out adjusted points — **1st gets 45** (up from 40 to account for the extra stage points in play), 2nd gets 35, 3rd gets 34, and so on down by 1 from there.

**Are you in favor of adding in-race stages with stage points?**
- ✅ Yes
- ❌ No
- 💬 Yes, but with different point values (explain below)

## 8️⃣ INCIDENT PENALTIES & DQ THRESHOLD

Currently, incident penalties work like this:
- 20 incidents → **-1 point**
- 30 incidents → **-2 points**
- 40+ incidents → **-3 points** (caps here, no further penalty)

I want to tighten this up. Pick the option you prefer:

**Option A — Add a DQ threshold (my recommendation):**
| Incidents | Penalty |
|-----------|---------|
| 20 | -1 |
| 30 | -2 |
| 40 | -3 |
| 50+ | **DQ — last place finish regardless of position** |

**Option B — Increase severity across the board:**
| Incidents | Penalty |
|-----------|---------|
| 20 | -2 |
| 30 | -3 |
| 40 | -4 |
| 50 | -5 |

**Option C — Uncapped sliding scale:**
Keep current penalties but **don't cap at 40** — every additional 10 incidents drops another point:
| Incidents | Penalty |
|-----------|---------|
| 20 | -1 |
| 30 | -2 |
| 40 | -3 |
| 50 | -4 |
| 60 | -5 |
| ...and so on | |

**Option D — Keep current system as-is**
